ภาพฉากหลายชั้น (ดูรายละเอียดใน js/scenery.js)

ชื่อไฟล์:  <ชุด>_<ชั้น>.png      ชั้น = sky | far | mid | ground
  ชุด  = m1, m2, ... m6 (ตามเลขด่าน)   หรือชื่อที่ตั้งเองด้วย  scene: 'city'  ในด่านของ missions.js
         ด่านที่ไม่มีไฟล์ของตัวเองจะใช้ชุด  default  (default_far.png ...)   ไม่มีเลย = ฉากโค้ดเดิมของชั้นนั้น
  เมนู / Hangar / หน้าสรุปผล ใช้ชุด default

ขนาดแนะนำ (วาด 2 เท่าของพิกเซลเกม):
  sky     1600 x 760   ฟ้า เลื่อนช้ามาก (ซ้ายขวาต่อกันได้)
  far     3200 x 760   ฉากไกล ต่อซ้ายขวาได้ PNG โปร่งใสตั้งแต่ฟ้า (เลื่อน 0.15 เท่ากล้อง)
  mid     3200 x 760   ฉากกลาง ต่อซ้ายขวาได้ PNG โปร่งใส (เลื่อน 0.45 เท่ากล้อง)
  ground  512  x 140   พื้น ต่อซ้ายขวาได้ เลื่อนตามโลกจริง ขอบบนภาพ = ระดับพื้นที่หุ่นยืน

กติกา: ความสูงภาพ sky/far/mid ถูกย่อให้พอดีเหนือพื้น (380 พิกเซลเกม) ความกว้างตามสัดส่วน — ขนาดอื่นก็ใช้ได้ถ้าสัดส่วนความสูงใกล้เคียง
       ขอบซ้ายกับขอบขวาของภาพต้องต่อกันได้ ไม่งั้นจะเห็นรอยต่อตอนเลื่อน
       ฉากไกล/กลางให้ล่างของภาพชิดเส้นพื้น (ตึกยืนบนพื้น) ส่วนบนโปร่งใสเพื่อเห็นฟ้า
ปรับความเร็วเลื่อนที่ SCENE_FACTOR ใน js/scenery.js
