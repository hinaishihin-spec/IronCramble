# Wanzer Prototype

เกม Side-Scrolling Mecha Action สไตล์ Gun Hazard (HTML5 Canvas + JavaScript ล้วน ไม่ใช้ไลบรารีใดๆ)

## วิธีเปิดเล่น

ดับเบิลคลิก `index.html` ได้เลย ไม่ต้องติดตั้งหรือเปิดเซิร์ฟเวอร์

> ไฟล์ใน `js/` เป็น script ธรรมดา ไม่ใช่ ES Modules เพราะ ES Modules จะเปิดจากการดับเบิลคลิกไฟล์ (file://) ไม่ได้

อยากได้ไฟล์เดียวไว้ส่งให้คนอื่น: `python3 build.py` จะสร้าง `dist/wanzer-single.html`

## โครงสร้างไฟล์

| ไฟล์ | หน้าที่ |
|---|---|
| `js/config.js` | ค่าคงที่ทั้งหมด (ความเร็ว ดาเมจ คูลดาวน์ รางวัลภารกิจ) ปรับสมดุลเกมที่นี่ |
| `js/save.js` | เซฟ/โหลดด้วย LocalStorage และออบเจกต์ `profile` (เลเวล EXP เงิน) |
| `js/upgrades.js` | กฎอัปเกรด/ซื้ออาวุธ: ราคา เงื่อนไข หักเงิน + สเตตัสที่ได้ (`maxHp()`, `maxFuel()`) |
| `js/input.js` | สถานะคีย์บอร์ด/เมาส์ แล้วส่งต่อให้ฉากปัจจุบัน |
| `js/effects.js` | ประกายไฟ ระเบิด ตัวเลขลอย จอสั่น เงา Dash |
| `js/world.js` | กล้อง ฉากหลัง พื้น |
| `js/items.js` | ไอเทมดรอป (HP / เติมโล่และบูสเตอร์ / เงิน) |
| `js/player.js` | หุ่นผู้เล่น: เดิน กระโดด Dash Jetpack โล่ รับดาเมจ EXP เลเวลอัป |
| `js/parts.js` | **ชิ้นส่วนหุ่น** `WANZER_PARTS` (หัว/ลำตัว/แขน/ขา/แพ็กหลัง) + สูตรสเตตัสรวม + ซื้อ/สวมพาร์ท |
| `js/enemy.js` | ศัตรู (Walker, Drone, Heavy Tank): AI ยิงตอบ เกราะ รับดาเมจ ตาย |
| `js/enemy2.js` | ศัตรูใหม่ด่าน 03-04: **EnemyChopper** (`makeChopper/updateChopper/drawChopper`), **EnemySniper** (`makeSniper/updateSniper/drawSniper`) + เลเซอร์ไซต์ + กระสุนสไนเปอร์ |
| `js/weapons.js` | อาวุธทุกชนิด (MG, Missile, Dual MG, Dual Missile, Shotgun, Laser) + กระสุนศัตรู |
| `js/boss.js` | บอสท้ายด่าน **Mobile Fortress**: AI 2 เฟส ท่าโจมตี ฉากระเบิด ป้าย WARNING หลอด HP บอส |
| `js/boss2.js` | บอสด่าน 03-04: **Giant Hopper**, **Boss Sniper** + ตัวเลือกบอสตาม `kind` (`makeBossFor/updateBoss/drawBoss`) |
| `js/missions.js` | **ข้อมูลด่าน** (ความยาว เงื่อนไขปลดล็อก รางวัล เวฟศัตรู) + ฟังก์ชันเลือก/ปลดล็อกด่าน |
| `js/mission.js` | เริ่มด่าน ระบบสปอว์นตามระยะทาง (เวฟ) ล็อกกล้องเมื่อถึงบอส เช็กจบด่าน สถิติรอบนี้ (`run`) |
| `js/ui.js` | HUD ระหว่างเล่น หน้าเมนู หน้าสรุปผล ปุ่ม (วาดอย่างเดียว ไม่มีตรรกะ) |
| `js/hangar.js` | ฉาก Hangar (อู่ซ่อม/ร้านค้า): รับคลิก/ปุ่มแล้วเรียก `buyUpgrade()` |
| `js/scenes.js` | ระบบเปลี่ยนฉาก: `menu` → `hangar` → `play` → `complete` → `hangar` |
| `js/main.js` | เปิดฉากแรก + game loop (ต้องโหลดเป็นไฟล์สุดท้าย) |

ลำดับ `<script>` ใน `index.html` สำคัญ ถ้าเพิ่มไฟล์ใหม่ให้ใส่ก่อน `main.js`

## ระบบฉาก (State Management)

ทุกฉากมีรูปแบบเหมือนกัน: `{ enter(data), update(dt), render(), keydown(e), mousedown() }`

- `Scenes.go('play')` เปลี่ยนฉาก และเรียก `enter()` ของฉากใหม่
- เพิ่มฉากใหม่ (เช่น ร้านค้า): สร้าง object ฉากใน `scenes.js` แล้วเพิ่มใน `Scenes.registry`

## ระบบด่าน (Mission Progression)

ข้อมูลด่านทั้งหมดอยู่ใน `js/missions.js` (อาร์เรย์ `MISSIONS`) เพิ่มด่านใหม่ = เพิ่มออบเจกต์หนึ่งก้อน

| ด่าน | ความยาว | ปลดล็อก | ศัตรู |
|---|---|---|---|
| Mission 01 | 600 m | เริ่มต้น | หุ่นเดินดิน 2 + โดรน 2 (3 เวฟ ที่ 150 / 330 / 480 m) |
| Mission 02 IRON CORRIDOR | 1200 m | `Missions Cleared >= 1` | 8 เวฟ (ศัตรู 21 ตัว มี **Heavy Tank** 3 คัน) แล้วบอส **Mobile Fortress** ที่ 1000 m |
| Mission 03 STORM RIDGE | 1300 m | `Missions Cleared >= 2` | 8 เวฟ (มี **Chopper** และ **Sniper**) แล้วบอส **Giant Hopper** ที่ 1100 m |
| Mission 04 LONG SHOT | 1500 m | `Missions Cleared >= 3` | 10 เวฟ (Sniper หลายตัว + Chopper) แล้วบอส **Boss Sniper** ที่ 1300 m |

- **Distance Trigger**: แต่ละเวฟมี `at` (เมตร) เมื่อผู้เล่นเดินถึงระยะนั้น ศัตรูจะเกิดนอกจอทางขวาแล้วเดินเข้าหา (10 px = 1 m) ไม่เกิดพร้อมกันทั้งด่าน จึงเบาเครื่องและมีจังหวะ ถ้า Dash ข้ามหลายเวฟ ทุกเวฟที่ข้ามจะเกิดครบ
- **จบด่าน**: เมื่อทุกเวฟเกิดแล้วและศัตรูตายหมด (ไม่ใช่แค่เดินถึงปลายทาง)
- **Heavy Tank**: HP 180, เกราะลดดาเมจ 35% (ยกเว้น Homing Missile ที่เจาะเกราะ), เดินช้า, หยุดยิงที่ระยะ 380 px, เล็งแล้วชาร์จปากกระบอกเรือง 0.7 วินาทีก่อนยิงกระสุนปืนใหญ่ (ดาเมจ 32, ทำให้โล่เสียพลังมากกว่าปกติ) ดรอปไอเทม 2 ชิ้น ปรับค่าที่ `TANK_*` ใน `config.js`
- **เลือกด่านใน Hangar**: ปุ่ม `<` `>` หรือ A / D ด่านที่ยังล็อกดูได้แต่ LAUNCH กดไม่ได้ จบด่านที่ปลดล็อกใหม่จะถูกเลือกให้อัตโนมัติ
- ใช้ค่า `missions` (Missions Cleared) ในเซฟเป็นตัวปลดล็อก จึงไม่ต้องเปลี่ยนโครงสร้างเซฟ

## Boss Fight: Mobile Fortress (ท้ายด่าน Mission 02)

กำหนดในข้อมูลด่านด้วย `boss: { at: 1000, name: 'MOBILE FORTRESS' }` ใน `js/missions.js` (ด่านไหนใส่ก็มีบอส) ค่าปรับสมดุลอยู่ที่ `BOSS_*` ใน `config.js`

1. **Camera Lock**: เดินถึง 1000 m กล้องหยุดนิ่ง ผู้เล่นถอยหลัง/เดินเลยขอบจอไม่ได้ (มีเส้นแดงที่ขอบจอ) ขึ้นป้าย `WARNING: BOSS APPROACHING` 3.2 วินาที บอสเลื่อนเข้าจอจากขวา (ช่วงนี้ยังโดนไม่ได้)
2. **ตัวบอส**: 120x120 px, HP 500, เกราะลดดาเมจปืนกล/เลเซอร์ 25% (มิสไซล์เจาะเต็มแรง) เดินช้าๆ ไปมาในครึ่งขวาของจอ
3. **เฟส 1 (HP 500-250)**: ยิงปืนกลหนัก (เป็นชุด) สลับกับเปิดฮัตช์ปล่อยโดรนลูกน้องครั้งละ 2 (มีได้พร้อมกันไม่เกิน 4, ไม่นับยอดศัตรู, ไม่ให้ EXP)
4. **เฟส 2 (HP ต่ำกว่า 250)**: ตัวบอสเรืองแสงแดง คำรามเปลี่ยนเฟส แล้วยิง **Spread Missiles 3 ลูกพร้อมกัน** (ท่อยิงเรืองแสงเตือน 0.55 วินาที มิสไซล์เลี้ยวเข้าหาผู้เล่นเบาๆ) สลับกับปืนกลสั้นๆ
5. **บอสพัง**: ระเบิดต่อเนื่อง 2.2 วินาที -> ระเบิดใหญ่ + แสงขาว -> ได้ **150 Credits** (+200 EXP) ศัตรูที่เหลือพังตามทั้งหมด -> หน้า Mission Complete (โบนัสด่านและรางวัลบอสแสดงแยกกัน)

หมายเหตุ: ด่านที่มีบอสจะจบเมื่อบอสพังเท่านั้น เวฟศัตรูทั้งหมดจึงต้องอยู่ก่อนระยะบอส (เวฟสุดท้ายของ Mission 02 อยู่ที่ 940 m)

## ศัตรูและบอสใหม่ (ด่าน 03-04)

ชนิดในเวฟ: `['chopper', offset]`, `['sniper', offset]` (offset ของ sniper = เยื้องเข้าซ้ายจากขอบจอขวา ถ้ามีหลายตัว) ปรับค่าที่ `CHOPPER_*`, `SNIPER_*`, `HOPPER_*`, `BSNIPER_*` ใน `config.js`

- **EnemyChopper**: HP 70 บินสูงที่ความสูงคงที่ ตามแกน X ของผู้เล่นช้าๆ (55 px/s) ยิงมิสไซล์ 2 ลูกเฉียงลงทุก 3 วินาที (แท่นยิงเรืองแสงเตือน 0.5 วินาที)
- **EnemySniper**: HP 24 เกราะบาง ยืนนิ่งชิดขอบจอขวา (ตามกล้อง) ระยะยิง 920 px (2 เท่าของหุ่นเดินดิน) เลเซอร์ไซต์แดง 1.5 วินาที: 1.1 วินาทีแรกตามผู้เล่น แล้ว **ล็อกเส้น** 0.4 วินาทีสุดท้าย (ขยับหนีออกจากเส้นเพื่อหลบ) จากนั้นยิงกระสุนความเร็ว 1500 px/s ดาเมจ 30
- **Giant Hopper** (บอสด่าน 03): 150x64, HP 600, 2 เฟส บินบนจอตามแกน X ช้าๆ ยิง **ฝูงมิสไซล์เฉียงลง** ทุก 3 วินาที (เฟส 1 = 5 ลูก, เฟส 2 = 8 ลูก และบินเร็วขึ้น)
- **Boss Sniper** (บอสด่าน 04): 84x130, HP 520, 2 เฟส ยืนนิ่งขอบจอขวา เลเซอร์ไซต์ 1.5 วินาทีแล้วยิงกระสุนเร็ว เฟส 2 มีเลเซอร์ **2 เส้น** (เส้นที่สองเบี่ยงจากเส้นแรก) พักระหว่างนัดสั้นลง
- ด่านกำหนดชนิดบอสด้วย `boss: { at, name, kind: 'fortress' | 'hopper' | 'sniper' }`

## Hangar: ชิ้นส่วนหุ่น (Parts)

ข้อมูลพาร์ททั้งหมดอยู่ใน `WANZER_PARTS` (`js/parts.js`) ตัวแรกของทุกหมวด (`basic`, Basic Block) คือพาร์ทสี่เหลี่ยมธรรมดาที่สวมตั้งแต่เริ่มเกม ราคา 0

- **ใช้งาน**: กดแท็บหมวด (หรือกด 1-6) แล้วคลิกการ์ด (หรือกด Q W E R) ยังไม่มี = ซื้อ (หัก Credits) แล้วสวมทันที / มีแล้ว = สลับมาสวมฟรี
- **เซฟ**: `profile.equippedParts` (= `player.equippedParts` ออบเจกต์เดียวกัน) และ `profile.ownedParts` บันทึกลง LocalStorage ทุกครั้ง
- **สเตตัสในด่าน** (รวมจากพาร์ทที่สวมทั้งหมด):
  - Max HP = 100 + hpBonus ของหัว + ลำตัว
  - ความเร็วเดิน = MOVE_SPEED x speedBonus ของขา x (1 - น้ำหนักหัว x 0.003)
  - แรง Dash = x boostBonus ของขา
  - พลังโจมตี = x damageBonus ของแขน (คูณกับโบนัสเลเวล ใช้กับทุกอาวุธ)
  - เกจ Booster = boostDuration ของแพ็กหลัง x อัตราสิ้นเปลือง (ยิ่งนานยิ่งบินได้นาน)
  - ความเร็วชาร์จ Booster = energy ของลำตัว / 100
- เซฟเก่าที่เคยซื้ออัปเกรดเกราะ/ไอพ่นแบบรวม จะได้ Credits คืนเต็มจำนวนตอนโหลดครั้งแรก
- แท็บ "อาวุธ" ยังซื้ออาวุธ Laser / Dual MG / Dual Missile / Shotgun ได้เหมือนเดิม

## LocalStorage: แนวทางที่ใช้ในเกมนี้

1. **เก็บเฉพาะข้อมูลถาวร** `{ level, exp, gold, missions, ownedParts, equippedParts, laser, dualMg, dualMissile, shotgun }` เป็น JSON ใต้ key เดียว (`wanzer.save.v1`) ข้อมูลในด่าน (ตำแหน่งหุ่น ศัตรู) ไม่เก็บ
   เซฟเก่าที่ยังไม่มี 3 ฟิลด์หลังจะโหลดได้ปกติ (ได้ค่าเริ่มต้น 0) จึงยังไม่ต้องเปลี่ยนเลขเวอร์ชัน
2. **ใส่เลขเวอร์ชันใน key** เมื่อโครงสร้างเซฟเปลี่ยนในอนาคต ให้เปลี่ยนเป็น `v2` แล้วเขียนตัวแปลงจาก `v1`
3. **ครอบ try/catch ทุกครั้ง** LocalStorage อาจใช้ไม่ได้ (โหมดส่วนตัว ถูกบล็อก พื้นที่เต็ม) เกมต้องเล่นต่อได้ ไม่ใช่พัง
4. **ตรวจข้อมูลตอนโหลด (`sanitize`)** กัน JSON เสียหรือถูกแก้มือ บังคับให้เป็นตัวเลขในช่วงที่เกมรับได้
5. **เลือกจังหวะเซฟ** เกมนี้เซฟตอนได้ EXP ได้เงิน และจบภารกิจ (ข้อมูลเล็ก เขียนบ่อยได้) ไม่ต้องเซฟทุกเฟรม
6. **ค่าที่คำนวณได้ไม่ต้องเก็บ** เช่น พลังโจมตีคำนวณจากเลเวล (`1 + 0.03 x (เลเวล-1)`)
7. **ข้อจำกัด** ผู้เล่นล้างข้อมูลเบราว์เซอร์ก็หาย และแต่ละโดเมนมีเซฟแยกกัน หากต้องการเซฟข้ามเครื่องต้องมีเซิร์ฟเวอร์

ล้างเซฟทดสอบ: ปุ่ม NEW GAME ในเมนู หรือรัน `localStorage.removeItem('wanzer.save.v1')` ใน DevTools Console


## ระบบน้ำหนัก (Weight & Load) และสีตามซีรีส์
- `BODY` มี `maxLoad` (Basic 30 / Zeriot I 50 / Hammer I 80) ส่วน HEAD/ARMS/LEGS/BACKPACK มี `weight`
- `calculateTotalWeight()` = รวม weight ของหัว+แขน+ขา+แพ็กหลัง (ไม่นับลำตัว) · `isOverweight()` = รวม > maxLoad
- เกิน = ปุ่ม LAUNCH เป็นสีเทาเขียน `OVERWEIGHT` และ `HangarScene.launch()` ปฏิเสธการออกรบ
- ความเร็วเดิน ลด `WEIGHT_SPEED_PENALTY` (0.3%) ต่อน้ำหนัก 1 หน่วย · เกจไอพ่น ลด `WEIGHT_FUEL_PENALTY` (0.2%) ต่อหน่วย (parts.js)
- `SERIES_COLORS` + `partColor(cat)` กำหนดสีตามซีรีส์ (Zeriot `#4A5D4E`, Hammer `#2D3238`) ใช้ใน `drawPlayer()` (ด่าน) และ `drawMechModel()` (Hangar)

## ระบบอาวุธ 2 ช่อง (ปืน / มิสไซล์)

## อาวุธสองมือ (js/dualhand.js)
- มือขวา = ช่องปืนเดิม (คลิกซ้าย / จอย RT)  มือซ้าย = `equippedWeapon.gun2` (คลิกขวา / จอย LT)  มิสไซล์ = F (จอย X) เมื่อใส่อาวุธมือซ้าย (ไม่ใส่ = คลิกขวายังยิงมิสไซล์เหมือนเดิม)
- ถือสองมือ: ดาเมจปืนทั้งสองมือคูณ `DUAL_PENALTY` (0.8)  น้ำหนักรวมตามปกติ  อาวุธตัวเดียวกันถือสองมือไม่ได้
- ข้อมูลอาวุธใส่ฟิลด์ `hand: 'R'` (มือขวาเท่านั้น) หรือ `'L'` (มือซ้ายเท่านั้น) ได้ที่ `js/weapondb.js` ไม่ใส่ = ได้ทั้งสองมือ  เลเซอร์บังคับมือขวา
- Hangar แท็บปืน: ปุ่ม G (หรือปุ่ม "แก้ไข: มือ…") สลับมือที่แก้ไข  แขนซ้ายวาดซ้ำจากสไปรต์แขนเดิม อยู่หลังลำตัวและเข้มกว่า (DUAL_FAR_SHADE, DUAL_OFF_DX ใน dualhand.js)

## แขนท่าถือปืน (js/armaim.js)
`assets/parts/arms_<ไอดีพาร์ท>_aims.png` = ภาพแขนท่าถือปืน (เช่นแขนงอ) ใช้ตอนถืออาวุธแทนภาพแขนปกติ ไม่มีไฟล์ = ใช้ภาพปกติเหมือนเดิม  ใช้กับแขนมือซ้ายด้วย
วาดหันซ้ายเล็งแนวนอน  จุดไหล่/มือ/สเกล: `ARM_AIM_RIG` (ทุกพาร์ท) หรือ `aimRig: { a:[x,y], hand:[x,y], scale }` ในข้อมูลพาร์ท  ดูจุดด้วย `ARM_AIM_DEBUG = true`

## มิสไซล์สองไหล่ (js/missile2.js)
- ช่องมิสไซล์ที่สอง `equippedWeapon.missile2` = พอดไหล่ซ้าย  ใส่แล้วปุ่มมิสไซล์เดิม (คลิกขวา / F / X บนจอย) ยิงสลับสองพอดเอง แต่ละพอดมีคูลดาวน์ของตัวเอง  ไม่ใส่ = เล่นเหมือนเดิม
- ใช้ได้เฉพาะชนิดใน `POD2_TYPES` (Single / Dual / Swarm)  ไหล่ขวาถือ Beam / Orbital / Napalm อยู่ ช่องที่สองไม่ทำงาน  อาวุธชิ้นเดียวใส่สองไหล่ไม่ได้  น้ำหนักรวมตามปกติ
- Hangar แท็บมิสไซล์: ปุ่ม G หรือปุ่ม "ไหล่ขวา/ไหล่ซ้าย" สลับไหล่ที่แก้ไข  กดอาวุธที่อยู่ไหล่ซ้ายอีกครั้ง = ถอด
- ปรับค่า: `POD2_BACK` `POD2_UP` (ตำแหน่งพอดซ้าย) `POD2_SHADE` (ความเข้ม) `POD2_STAGGER` (จังหวะสลับ) ที่ต้นไฟล์

## Chip ทักษะ (js/chipdata.js + js/chips.js)
- ติดตั้งได้ 1 ชิ้น (`profile.equippedChip`) ไม่มีน้ำหนัก  Hangar: ปุ่ม "ชิป [K]" เปิดแผง แถวละหนึ่งชนิด ปุ่ม I / II / III ซื้อและสวมระดับนั้น (กดซ้ำ = ถอด)
- สุ่มเกิด (proc) โอกาส 10 / 15 / 20% ต่อการโจมตี มีช่วงพัก `CHIP_ICD` ต่อทักษะ: AP ยิงทะลุเกราะ, GUN2 ยิงคู่ปืนมือ, BATON2 ตีคู่, KNUCKLE2 ต่อยคู่, POD2 มิสไซล์คู่สองไหล่, HR / HL ปืน+มิสไซล์ไหล่ขวา/ซ้าย (ทักษะมิสไซล์ต้องถือมิสไซล์ชนิด POD2_TYPES)
- เพิ่มค่า (passive): HP, GUN ดาเมจปืน, SMASH ดาเมจอาวุธประชิด, DEF ลดดาเมจ (บวกเพิ่มจากเพดานของพาร์ท), BOOST แรงพุ่ง Dash
- ปรับข้อมูลที่ `CHIP_FAMILIES` (ค่า vals, ด่านที่ปลดล็อก mission), ราคา `CHIP_PRICE_*`, จำนวนครั้งปลดล็อก `CHIP_LV_CLEARS` ต้นไฟล์ chipdata.js
- ใส่ชิปใหม่: เพิ่มแถวใน `CHIP_FAMILIES` (ถ้าเป็น proc ต้องเพิ่มเงื่อนไขใน `chipOnGun` / `chipOnMissile` ที่ chips.js  ถ้าเป็น passive เพิ่มใน wrapper ด้านบนของ chips.js)
