ต้นแบบเกม Side-Scrolling Mecha Action สไตล์ Gun Hazard

  • ADเดินซ้าย / ขวา
  • WSpaceกระโดด / กดค้างกลางอากาศเพื่อบิน
  • S↓กดค้างเพื่อนั่ง/ย่อตัว (เดินช้าลง กระสุนสูงลอยข้ามหัว)
  • Shift+ A / D พุ่งตัว (Dash)
  • Qกดค้างเพื่อกางโล่ (ลดดาเมจ 80% เดินช้าลง ยิงไม่ได้)
  • เมาส์เล็ง 360 องศา คลิกซ้าย = ยิงปืน คลิกขวา = ยิงมิสไซล์ (ยิงพร้อมกันได้)
  • Fยิงมิสไซล์ (สำรองสำหรับเมาส์ที่ไม่มีปุ่มขวา)
  • 1–8ใน Hangar: เปลี่ยนหมวด (หัว / ลำตัว / แขน / ขา / แพ็กหลัง / ไหล่ / ปืน / มิสไซล์)
  • Q–Pใน Hangar: ซื้อและสวมรายการที่ 1–10 (หรือคลิกเมาส์)
  • ADใน Hangar: เลือกด่าน · Enter = LAUNCH
  • M-=ปิด/เปิดเสียง · ลด/เพิ่มระดับเสียง
  • Rลองใหม่เมื่อหุ่นพัง
  • Escกลับเมนูหลัก
  • 🎮 จอยสติ๊กซ้าย เดิน · สติ๊กขวา เล็ง · A กระโดด/บิน · สติ๊กลง ย่อตัว · B หรือ RB พุ่ง (ดันสติ๊กซ้ายด้วย) · LB โล่ · RT ยิงปืน · LT หรือ X มิสไซล์ · Back = เมนู
  • 🎮 เมนูสติ๊กซ้าย/D-pad ขยับเคอร์เซอร์ · A คลิก · B ย้อนกลับ · Start ยืนยัน/LAUNCH · LB/RB เปลี่ยนหมวด · LT/RT เลือกด่าน · Y ถอดอาวุธพรีวิว
